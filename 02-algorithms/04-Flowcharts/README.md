# 🧩 Fluxogramas

> Playground dedicado à prática de **representação visual de algoritmos por meio de fluxogramas**.

## 🎯 Objetivo

Desenvolver a capacidade de representar visualmente o fluxo de um algoritmo, tornando clara a sequência de execução, as entradas, os processamentos, as saídas e as decisões.

## 🧠 Conceito

Um fluxograma é uma representação gráfica de um algoritmo.

Ele utiliza **símbolos padronizados** conectados por setas para representar as etapas e o fluxo da solução.

```text
Problema
   ↓
Algoritmo
   ↓
Fluxograma
   ↓
Visualização do fluxo
   ↓
Validação da lógica
````

O objetivo não é aprender uma ferramenta específica, mas desenvolver a capacidade de transformar a sequência lógica de um algoritmo em uma representação visual.

* * *

## 📚 Organização

Os exercícios serão divididos de acordo com o nível de complexidade:

```
04-flowcharts/
│
├── 01-basic/
├── 02-intermediate/
└── 03-advanced/
```

### 🟢 Basic

Fluxogramas com sequências simples de entrada, processamento e saída.

### 🟡 Intermediate

Fluxogramas que envolvem múltiplas etapas e estruturas de decisão ou repetição.

### 🔴 Advanced

Fluxogramas de problemas maiores, envolvendo diferentes caminhos de execução e maior complexidade lógica.

* * *

## 🔍 Processo

Para cada problema:

```
1. Entender o problema
        ↓
2. Identificar as etapas do algoritmo
        ↓
3. Identificar entradas e saídas
        ↓
4. Identificar processamentos
        ↓
5. Identificar decisões e repetições
        ↓
6. Representar o fluxo
        ↓
7. Validar o fluxo
```

O fluxograma deve representar uma solução que já foi estruturada anteriormente.

A implementação em Java **não faz parte desta etapa**.

## 🔒 Restrições

Durante este Playground:

-   ❌ Não começar pelo código Java.
-   ❌ Não utilizar sintaxe específica de Java dentro do fluxograma.
-   ❌ Não adicionar regras que não existem no problema.
-   ❌ Não alterar o problema para facilitar a representação.
-   ❌ Não ignorar etapas do algoritmo.
-   ❌ Não criar fluxogramas sem antes compreender o fluxo da solução.
-   ❌ O foco é representar e validar a lógica visualmente.
