# 🧩 Algoritmos

> Playground dedicado à prática de **algoritmos**, desde a definição do problema até a representação e validação da solução.

## 🎯 Objetivo

Desenvolver a capacidade de transformar um problema em uma **sequência lógica e organizada de passos**, preparando a solução antes da implementação em Java.

## 🧠 Conceito

Um algoritmo é uma sequência de passos organizados para resolver um problema ou executar uma tarefa.

```text
Problema
   ↓
Definição
   ↓
Entradas
   ↓
Processamento
   ↓
Saída
   ↓
Solução
```

O foco deste Playground é aprender a **estruturar a solução antes de escrever código**.

---

## 📚 Organização

Os exercícios serão divididos em etapas:

```text
02-algorithms/
│
├── 01-problem-definition/
├── 02-input-processing-output/
├── 03-pseudocode/
├── 04-flowcharts/
└── 05-dry-run/
```

### 01 — Problem Definition

Definir claramente o problema, identificando objetivo, entradas, saídas, regras e restrições.

### 02 — Input, Processing & Output

Identificar os dados de entrada, o processamento necessário e o resultado produzido.

### 03 — Pseudocode

Representar a solução utilizando uma linguagem estruturada e independente de uma linguagem de programação.

### 04 — Flowcharts

Representar visualmente o fluxo de execução do algoritmo.

### 05 — Dry Run

Simular manualmente a execução do algoritmo utilizando valores de entrada.

---

## 🔍 Processo

A construção dos algoritmos seguirá esta sequência:

```text
1. Definir o problema
        ↓
2. Identificar entradas, processamento e saída
        ↓
3. Representar a solução em pseudocódigo
        ↓
4. Representar o fluxo
        ↓
5. Executar um Dry Run
```

A implementação em Java **não faz parte deste módulo**.

O objetivo é desenvolver a capacidade de construir e validar o algoritmo antes de transformá-lo em código.

## 🔒 Restrições

Durante este Playground:

- Não começar pela implementação.
- Não pensar inicialmente em Java.
- Não pular diretamente para o código.
- Não adicionar requisitos que não fazem parte do problema.
- Construir e validar o algoritmo antes da implementação.

---

## 💡 Princípio

> **Antes de escrever código, defina o problema e construa uma sequência lógica de passos para resolvê-lo.**
