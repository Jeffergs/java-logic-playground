# 🧩 Pseudocódigo

> Playground dedicado à prática de **representação de algoritmos por meio de pseudocódigo**, antes da implementação em uma linguagem de programação.

## 🎯 Objetivo

Desenvolver a capacidade de representar uma solução de forma **estruturada, clara e independente de uma linguagem de programação**.

## 🧠 Conceito

Pseudocódigo é uma forma de descrever os passos de um algoritmo utilizando uma linguagem próxima da linguagem humana, mas com uma estrutura organizada.

```text
Problema
   ↓
Análise
   ↓
Pseudocódigo
   ↓
Implementação
```

O pseudocódigo permite concentrar a atenção na **lógica da solução**, sem depender da sintaxe do Java.

### Exemplo

Problema:

> Receber duas notas, calcular a média e exibir o resultado.

Pseudocódigo:

```text
Início

Leia nota1
Leia nota2

media ← (nota1 + nota2) / 2

Escreva media

Fim
```

O objetivo não é aprender uma sintaxe específica de pseudocódigo.

O objetivo é conseguir **expressar claramente a sequência lógica de uma solução**.

---

## 🔍 Processo

Para cada exercício:

```text
1. Entender o problema
        ↓
2. Identificar a lógica necessária
        ↓
3. Organizar os passos
        ↓
4. Escrever o pseudocódigo
        ↓
5. Verificar a sequência lógica
```

O pseudocódigo será construído **antes da implementação em Java**.

---

## 📚 Organização

Os exercícios serão divididos de acordo com o nível de complexidade:

```text
03-pseudocode/
│
├── 01-basic/
├── 02-intermediate/
└── 03-advanced/
```

### 🟢 Basic

Problemas simples, com sequência de passos predominantemente linear.

### 🟡 Intermediate

Problemas que envolvem decisões, diferentes caminhos de execução ou mais de uma etapa de processamento.

### 🔴 Advanced

Problemas que combinam diferentes estruturas e exigem uma organização mais cuidadosa da lógica.

## 🔒 Restrições

Durante este Playground:

- Não escrever código Java.
- Não utilizar sintaxe específica de Java.
- Não criar classes ou métodos.
- Não se preocupar com tipos de dados específicos de uma linguagem.
- Não adicionar regras que não fazem parte do problema.
- Não transformar pseudocódigo em uma implementação.
- Concentrar-se na **lógica e na sequência dos passos**.

---

## 💡 Princípio

> **Primeiro organize a lógica da solução; depois preocupe-se com a sintaxe da linguagem de programação.**
