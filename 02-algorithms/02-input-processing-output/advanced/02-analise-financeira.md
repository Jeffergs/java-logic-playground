## 🧩 Exercício 02 — Análise financeira

### 🎯 Problema

Uma instituição financeira precisa analisar uma solicitação de crédito.

O processo recebe:

-   dados do cliente;
-   valor solicitado;
-   quantidade de parcelas;
-   renda;
-   compromissos financeiros;
-   histórico de pagamentos.

A análise deverá produzir informações intermediárias antes de chegar ao resultado final da solicitação.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamentos**
3.  **Saídas**
4.  **Relações entre os dados**
5.  **Dependências entre os processamentos**
6.  **Resultados intermediários**
7.  **Resultado final**
8.  **Quais informações são utilizadas em cada processamento**

Use:

```
Entradas:
...

Processamentos:
...

Saídas:
...

Relação entre dados:
...

Dependências:
...

Resultados intermediários:
...

Resultado final:
...
```
