## 🧩 Exercício 01 — Soma de valores

### 🎯 Problema

Um sistema precisa receber **dois valores**, realizar a operação necessária e informar o **resultado da soma**.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamento**
3.  **Saída**

Use:

```
Entradas:
...

Processamento:
...

Saída:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar entradas adicionais.
-   ❌ Não adicionar operações que não foram solicitadas.

**Foco:** identificar claramente o fluxo:

```
Entrada → Processamento → Saída
```
