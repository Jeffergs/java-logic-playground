## 🧩 Exercício 01 — Cálculo de pedido

### 🎯 Problema

Uma loja precisa processar um pedido contendo **vários produtos**.

Para cada produto, são informados:

-   preço unitário;
-   quantidade comprada.

O pedido também possui um **percentual de desconto**.

O sistema deverá calcular o valor dos produtos, aplicar o desconto e informar o **valor final do pedido**.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamento**
3.  **Saídas**
4.  **Relação entre as entradas e o processamento**
5.  **Informações necessárias para produzir cada saída**

Use:

```
Entradas:
...

Processamento:
...

Saídas:
...

Relação entre dados:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar impostos, frete ou outras regras.
-   ❌ Não resolver o algoritmo.
-   ❌ Não tratar cada produto como se fosse necessariamente uma única entrada isolada.

### 🎯 Desafio

Agora existem **múltiplos dados de entrada relacionados**.

Você precisa perceber a diferença entre:

```
Dados de entrada
       ↓
Agrupamento dos dados
       ↓
Processamento
       ↓
Resultado
```

O objetivo é identificar corretamente **quais dados participam de cada etapa do processamento**.
