## 🧩 Exercício 05 — Cálculo de frete

### 🎯 Problema

Uma loja virtual precisa calcular o **valor do frete** de um pedido.

Para realizar o cálculo, são informados:

-   peso do pedido;
-   distância até o endereço de entrega;
-   valor base do frete.

O sistema deverá calcular o valor do frete e informar o resultado.
