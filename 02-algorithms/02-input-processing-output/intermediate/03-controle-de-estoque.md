## 🧩 Exercício 03 — Controle de estoque

### 🎯 Problema

Uma loja precisa processar uma solicitação de estoque.

Para cada solicitação, são informados:

-   quantidade atual em estoque;
-   quantidade solicitada;
-   preço unitário do produto.

O sistema deverá verificar a quantidade disponível, determinar se a solicitação pode ser atendida e calcular o valor correspondente aos produtos solicitados.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamento**
3.  **Saídas**
4.  **Relação entre os dados**
5.  **Quais dados são utilizados em cada etapa do processamento**

Use:

```
Entradas:
...

Processamento:
...

Saídas:
...

Relação entre dados:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar regras de estoque.
-   ❌ Não adicionar informações que não foram apresentadas.
-   ❌ Não resolver o algoritmo.

### 🎯 Desafio

Agora você precisa relacionar **processamento condicional e cálculo**:

```
Entradas
   ↓
Verificação
   ↓
Decisão
   ↓
Processamento
   ↓
Saídas
```

O objetivo é identificar quais dados participam da **verificação**, quais participam do **cálculo** e quais resultados precisam ser produzidos.
