## 🧩 Exercício 02 — Folha de pagamento

### 🎯 Problema

Uma empresa precisa processar a folha de pagamento de seus funcionários.

Para cada funcionário, são considerados:

-   salário bruto;
-   quantidade de horas extras;
-   valor das horas extras;
-   valor dos descontos.

O sistema deverá calcular o valor das horas extras, determinar o salário líquido de cada funcionário e apresentar o resultado da folha.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamento**
3.  **Saídas**
4.  **Relação entre os dados**
5.  **Quais dados são utilizados em cada etapa do processamento**

Use:

```
Entradas:
...

Processamento:
...

Saídas:
...

Relação entre dados:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar regras trabalhistas ou tributárias.
-   ❌ Não adicionar impostos ou descontos que não foram mencionados.
-   ❌ Não resolver o algoritmo.

### 🎯 Desafio

Agora você precisa lidar com **dados que alimentam diferentes etapas do processamento**:

```
              ┌──→ Processamento A ──→ Resultado A
Entrada ──────┤
              └──→ Processamento B ──→ Resultado B
                              ↓
                       Resultado final
```

O objetivo é identificar **o fluxo e a dependência dos dados**, sem ainda definir como o algoritmo será implementado.
