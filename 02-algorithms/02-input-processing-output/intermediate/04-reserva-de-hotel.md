## 🧩 Exercício 04 — Reserva de hotel

### 🎯 Problema

Um hotel precisa processar uma solicitação de reserva.

Para cada solicitação, são informados:

-   número de noites;
-   valor da diária;
-   quantidade de hóspedes.

O sistema deverá calcular o valor da hospedagem e informar o resultado da reserva.

### 🧠 Sua tarefa

Identifique:

1.  **Entradas**
2.  **Processamento**
3.  **Saídas**
4.  **Relação entre os dados**
5.  **Quais dados são utilizados em cada etapa do processamento**
