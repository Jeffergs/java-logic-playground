## 🧠 Conceito

**Reconhecimento de padrões** é identificar características, comportamentos ou estruturas que se repetem em diferentes problemas ou situações.

A ideia é perceber:

-   o que se repete;
-   o que é semelhante;
-   o que muda;
-   o que pode ser tratado de maneira semelhante.

### Exemplo simples

Imagine estes problemas:

```
Cadastro de usuário
Cadastro de funcionário
Cadastro de cliente
Cadastro de fornecedor
```

Apesar de serem problemas diferentes, podemos perceber uma estrutura semelhante:

```
Receber dados
     ↓
Validar dados
     ↓
Registrar dados
     ↓
Confirmar operação
```

O reconhecimento do padrão não resolve os problemas. Ele permite **enxergar semelhanças entre eles**.

* * *

## 🎯 Objetivo do Playground

Desenvolver a capacidade de:

1.  Comparar problemas.
2.  Identificar elementos semelhantes.
3.  Encontrar comportamentos que se repetem.
4.  Separar padrões de características específicas.
5.  Utilizar padrões identificados para compreender novos problemas.

## 🔒 Restrições

Durante este Playground:

-   ❌ Não escrever código.
-   ❌ Não pensar inicialmente em Java.
-   ❌ Não tentar implementar uma solução.
-   ❌ Não confundir padrão com solução.
-   ❌ Não considerar dois problemas iguais apenas porque possuem o mesmo objetivo.

O foco é **identificar semelhanças e diferenças entre problemas**.

* * *

## 💡 Princípio

> **Antes de criar uma solução para um problema, procure estruturas ou comportamentos semelhantes em problemas que você já conhece.**
