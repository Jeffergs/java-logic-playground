## 🧩 Exercício 01 — Cadastro de usuários

### 🎯 Problema

Observe os seguintes processos:

```
Cadastro de usuário
Cadastro de funcionário
Cadastro de cliente
Cadastro de fornecedor
```

Todos são processos diferentes, mas possuem algumas etapas semelhantes.

### 🧠 Sua tarefa

Compare os quatro processos e identifique:

1.  O que existe em **comum** entre eles.
2.  O que é **específico** de cada processo.
3.  Quais etapas apresentam um **padrão de comportamento**.
4.  Quais características não fazem parte desse padrão.

Organize sua resposta, por exemplo:

```
Padrão identificado
│
├── Elemento comum
├── Elemento comum
└── Elemento comum

Diferenças
│
├── Usuário
├── Funcionário
├── Cliente
└── Fornecedor
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar classes ou métodos.
-   ❌ Não propor uma solução.
-   ❌ Não assumir informações que não foram apresentadas.

**O objetivo é apenas reconhecer os padrões existentes entre os processos.**
