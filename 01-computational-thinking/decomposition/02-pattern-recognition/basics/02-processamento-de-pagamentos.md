## 🧩 Exercício 02 — Processamento de pagamentos

### 🎯 Problema

Uma empresa possui diferentes formas de pagamento:

```
Pagamento com cartão
Pagamento via PIX
Pagamento via boleto
Pagamento com carteira digital
```

Cada forma possui características próprias, mas todas fazem parte do processo de **pagamento de uma compra**.

### 🧠 Sua tarefa

Compare os quatro processos e identifique:

1.  O que existe em **comum** entre as formas de pagamento.
2.  O que é **específico** de cada forma.
3.  Quais etapas apresentam comportamentos semelhantes.
4.  Quais características diferenciam cada forma de pagamento.
5.  Quais elementos podem ser considerados parte de um **padrão geral de pagamento**.

Organize sua análise separando:

```
Padrões
│
├── Elementos comuns
├── Comportamentos comuns
└── Etapas comuns

Diferenças
│
├── Cartão
├── PIX
├── Boleto
└── Carteira digital
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar classes ou métodos.
-   ❌ Não propor uma implementação.
-   ❌ Não transformar o padrão encontrado em uma solução.

**O objetivo é reconhecer o que se repete e distinguir aquilo que é específico de cada processo.**
