## 🧩 Exercício 02 — Pedido de reembolso

### 🎯 Problema

Uma empresa precisa de um sistema para processar solicitações de reembolso de despesas realizadas por funcionários.

O processo deverá:

-   receber os dados da solicitação;
-   identificar o funcionário;
-   identificar a despesa;
-   verificar se a despesa está dentro das regras da empresa;
-   analisar os documentos apresentados;
-   aprovar ou rejeitar a solicitação;
-   registrar o resultado;
-   informar o funcionário sobre a decisão.

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não pensar em banco de dados.
-   ❌ Não criar classes ou métodos.
-   ❌ Não resolver as regras de negócio.

### 🧠 Sua tarefa

Faça a **decomposição do processo**, identificando:

1.  As partes principais.
2.  Os subprocessos de cada parte.
3.  As dependências entre as etapas.
4.  Onde uma etapa ainda precisa ser decomposta.

O objetivo é produzir uma estrutura suficientemente clara para que, posteriormente, outra pessoa consiga implementar a solução a partir dela.
