## 🧩 Exercício 02 — Sistema de atendimento

### 🎯 Problema

Uma empresa possui diferentes canais de atendimento:

```
Atendimento presencial
Atendimento telefônico
Atendimento por chat
Atendimento por e-mail
```

Cada canal possui características próprias, mas todos fazem parte do processo de **atendimento de uma solicitação do cliente**.

### 🧠 Sua tarefa

Analise os quatro canais e identifique:

1.  **Padrões comuns** entre os diferentes canais.
2.  **Padrões dentro de outros padrões**, quando existirem.
3.  Comportamentos que possuem a mesma estrutura, mesmo sendo executados de formas diferentes.
4.  Características específicas de cada canal.
5.  Relações entre os padrões encontrados.
6.  Quais elementos **não devem ser agrupados**, apesar de apresentarem alguma semelhança.

Organize sua análise de forma hierárquica:

```
Atendimento
│
├── Padrão geral
│   ├── ...
│   └── ...
│
├── Padrão específico
│   ├── ...
│   └── ...
│
└── Particularidades
    ├── Presencial
    ├── Telefone
    ├── Chat
    └── E-mail
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar classes ou métodos.
-   ❌ Não propor uma implementação.
-   ❌ Não transformar os padrões encontrados em uma solução.
-   ❌ Não inventar regras que não foram apresentadas.

### 🎯 Desafio

Este é o **último exercício de Reconhecimento de Padrões**.

O objetivo é conseguir enxergar **estruturas recorrentes em problemas diferentes**, inclusive quando essas estruturas aparecem em níveis diferentes de abstração.
