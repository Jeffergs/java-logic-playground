## 🧩 Exercício 01 — Sistema de transporte

### 🎯 Problema

Uma empresa precisa representar diferentes tipos de transporte utilizados para deslocar pessoas:

```
Ônibus
Táxi
Metrô
Avião
```

Cada meio de transporte possui diversas características e informações próprias. Porém, o objetivo do sistema é representar apenas as informações **necessárias para entender o deslocamento de uma pessoa de um ponto até outro**.

### 🧠 Sua tarefa

Para cada meio de transporte, identifique:

1.  Quais informações são **essenciais** para representar o deslocamento.
2.  Quais informações são **detalhes específicos** de cada transporte.
3.  Quais detalhes podem ser ignorados sem prejudicar a representação do deslocamento.
4.  Qual seria uma **representação simplificada** que poderia ser utilizada para todos eles.
5.  Quais informações precisam continuar específicas de cada tipo.

Organize sua análise:

```
Transporte
│
├── Informações essenciais
│   ├── ...
│   └── ...
│
├── Informações específicas
│   ├── ...
│   └── ...
│
└── Informações que podem ser ignoradas
    ├── ...
    └── ...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar classes ou métodos.
-   ❌ Não definir uma implementação.
-   ❌ Não considerar detalhes técnicos do sistema.
-   ❌ Não eliminar uma informação simplesmente porque ela parece pouco importante.

### 🎯 Objetivo

O exercício é determinar **qual nível de informação é adequado ao objetivo apresentado**.

> A mesma informação pode ser essencial em um problema e irrelevante em outro.
