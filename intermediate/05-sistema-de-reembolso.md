## 🧩 Exercício 05 — Sistema de reembolso

### 🎯 Problema

Uma empresa precisa de um sistema para processar **solicitações de reembolso** realizadas por seus funcionários.

O sistema deverá:

-   receber os dados do funcionário;
-   receber os dados da despesa;
-   receber os documentos relacionados à despesa;
-   verificar se a solicitação pode ser processada;
-   analisar a solicitação;
-   informar o resultado da análise;
-   registrar a decisão.

### 🧠 Sua tarefa

Faça a **definição do problema**, identificando:

1.  **Objetivo**
2.  **Entradas**
3.  **Saídas**
4.  **Regras**
5.  **Restrições**
6.  **Informações não especificadas**

Use:

```
Objetivo:
...

Entradas:
...

Saídas:
...

Regras:
...

Restrições:
...

Informações não especificadas:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar regras de reembolso.
-   ❌ Não definir valores máximos ou mínimos.
-   ❌ Não decidir quais despesas são reembolsáveis.
-   ❌ Não assumir quais documentos são obrigatórios além dos mencionados.
-   ❌ Não resolver o problema.

### 🎯 Desafio

Neste exercício, preste atenção à diferença entre **regra** e **informação ausente**.

Por exemplo:

```
"O sistema deve verificar se a solicitação pode ser processada."
```

Isso informa **o que precisa ser feito**, mas não informa **quais critérios determinam se ela pode ser processada**.

Essa distinção faz parte da definição correta do problema.
