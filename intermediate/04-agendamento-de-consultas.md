## 🧩 Exercício 04 — Agendamento de consultas

### 🎯 Problema

Uma clínica precisa de um sistema para gerenciar o **agendamento de consultas**.

O sistema deverá:

-   receber os dados do paciente;
-   receber os dados do profissional;
-   receber a data e o horário desejados;
-   verificar a disponibilidade;
-   verificar as condições necessárias para o agendamento;
-   registrar a consulta;
-   informar o resultado do agendamento.

### 🧠 Sua tarefa

Faça a **definição do problema**, identificando:

1.  **Objetivo**
2.  **Entradas**
3.  **Saídas**
4.  **Regras**
5.  **Restrições**
6.  **Informações não especificadas**

Use:

```
Objetivo:
...

Entradas:
...

Saídas:
...

Regras:
...

Restrições:
...

Informações não especificadas:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar regras de agendamento.
-   ❌ Não assumir horários ou disponibilidades.
-   ❌ Não definir condições que não foram apresentadas.
-   ❌ Não resolver o problema.

### 🎯 Desafio

Neste exercício, diferencie principalmente:

```
O que o sistema recebe
        ↓
O que precisa verificar
        ↓
O que precisa produzir
        ↓
O que ainda não foi definido
```
