## 🧩 Exercício 02 — Análise de crédito

### 🎯 Problema

Uma instituição financeira precisa de um sistema que analise uma **solicitação de crédito**.

O sistema deverá receber:

-   os dados do cliente;
-   o valor solicitado;
-   a quantidade de parcelas;
-   informações utilizadas na análise financeira.

A partir dessas informações, o sistema deverá realizar a análise e informar o resultado da solicitação.

### 🧠 Sua tarefa

Faça a **definição do problema**, identificando:

1.  **Objetivo**
2.  **Entradas**
3.  **Saídas**
4.  **Regras**
5.  **Restrições**
6.  **Informações não especificadas**

Use:

```
Objetivo:
...

Entradas:
...

Saídas:
...

Regras:
...

Restrições:
...

Informações não especificadas:
...
```

### 🔒 Restrições

-   ❌ Não escrever código.
-   ❌ Não pensar em Java.
-   ❌ Não criar pseudocódigo.
-   ❌ Não criar fluxograma.
-   ❌ Não inventar critérios de aprovação.
-   ❌ Não definir limite de crédito.
-   ❌ Não definir taxas ou juros.
-   ❌ Não decidir o resultado da análise.
-   ❌ Não transformar o problema em algoritmo.

### 🎯 Desafio

Diferencie cuidadosamente:

```
Dado de entrada
      ≠
Regra de negócio
      ≠
Restrição
      ≠
Informação não especificada
```

O objetivo é perceber que uma definição de problema pode estar **incompleta mesmo quando possui várias informações de entrada**.
