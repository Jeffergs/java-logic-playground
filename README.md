## 🎯 Objetivo

Desenvolver a capacidade de **entender um problema, construir uma solução algorítmica e implementá-la em Java**.

A abordagem utilizada é:

```text
🧠 Pensar
   ↓
🧩 Decompor
   ↓
⚙️ Construir o algoritmo
   ↓
📝 Representar a solução
   ↓
☕ Implementar em Java
   ↓
🧪 Testar
   ↓
🐛 Depurar
   ↓
♻️ Refatorar
